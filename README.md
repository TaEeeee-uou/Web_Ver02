# LuminoaLink LP

ローカルで確認するための簡単な手順と、ダミー画像の差し替え方法をまとめたメモです。

## ローカルでの確認方法
1. このディレクトリを任意の場所に配置します。
2. ダブルクリックまたはブラウザで `index.html` を開きます。
3. フォントは Google Fonts を利用しているため、オフラインではシステムフォントにフォールバックします。

## 画像の差し替え
- `avatar.jpg` と `works/work1.jpg` 〜 `works/work6.jpg` を任意の画像で置き換えてください。
- レイアウトが崩れないよう、可能であれば 3:2（横長）程度の比率で用意することを推奨します。
- 画像サイズが大きい場合は、横幅 1600px 程度にリサイズすると読み込みが軽くなります。

## カラーの微調整
- `style.css` の先頭にある CSS カスタムプロパティ（`--color-*`）を編集することで配色を調整できます。
- 全体の余白や角丸半径、シャドウも同じ箇所でまとめて管理しています。

## メモ
- SNS リンクの URL、メールアドレスなどのテキストはそのまま置き換えて使用してください。
- 追加のセクションを増やしたい場合は、`.section` と `.section__card` の組み合わせを利用すると統一感が保てます。
